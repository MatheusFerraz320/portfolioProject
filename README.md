## Sobre

De **Policial Militar** a **Desenvolvedor Full-Stack**. Este portfólio reflete minha trajetória de transição de carreira e os projetos que construí ao longo do caminho.

Desenvolvido com **Next.js 15**, **TypeScript** e **Tailwind CSS 4**, o foco está em performance, boas práticas e experiência do usuário — os mesmos princípios que aplico em cada projeto que entrego.

---

## Stack

| Categoria | Tecnologias |
|-----------|-------------|
| **Core** | Next.js 15 (App Router), React 19, TypeScript |
| **Estilização** | Tailwind CSS 4, Framer Motion |
| **Ícones** | react-icons |
| **Fonte** | Poppins + Roboto Mono via next/font |

---

## Seções

- **Hero** — Apresentação com gradientes animados e CTA
- **Projetos** — Grid responsivo com filtros por categoria e modal de detalhes com descrição e links para o GitHub
- **Skills** — Tecnologias e ferramentas do dia a dia
- **Experiência** — Timeline interativa mostrando a transição PMSP → Dev
- **Sobre** — História completa da migração de carreira
- **Contato** — Cards diretos para GitHub, LinkedIn, Email e WhatsApp

---

## Como Rodar

```bash
# Clone
git clone https://github.com/MatheusFerraz320/Meu-Website.git

# Instale as dependências
npm install

# Rode em desenvolvimento
npm run dev

# Build de produção
npm run build

# Iniciar servidor de produção
npm start
```

## Estrutura

```
src/
├── app/
│   ├── layout.tsx          # Layout raiz (metadata, fonts, providers)
│   ├── page.tsx            # Página principal
│   └── globals.css         # Tailwind config + tema dark
├── components/
│   ├── layout/             # Navbar, Footer, SocialSidebar
│   └── sections/           # Hero, Projects, Skills, Experience, About, Contact
├── data/                   # Dados separados da UI (projetos, skills, experiência)
├── hooks/                  # Custom hooks
├── lib/                    # Utilitários (cn)
└── types/                  # Tipagens compartilhadas
```
